1Instalace Hermes Desktop

  1. Stáhni Hermes Desktop z https://hermes-agent.nousresearch.com (Windows i Mac) a nainstaluj. Balíček obsahuje všechno, nic dalšího k tomu instalovat nemusíš.
  2. Spusť ho. Průvodce prvním spuštěním tě provede výběrem modelu (krok 2).
  3. Chceš co nejjednodušší pohled? Settings → Appearance → Window & layout → Interface mode → Simple (zůstane chat a nastavení).

Máš už Claude Code, Codex nebo Cursor? Napiš Hermesovi: „Převezmi moje nastavení z Claude Code. Nejdřív mi ukaž, co převezmeš.“ Převezme instrukce, MCP servery a skills, hesla a klíče ne.

Záloha, kdyby balíček nešel nainstalovat: v PowerShellu iex (irm https://hermes-agent.nousresearch.com/install.ps1), pak nové okno a hermes desktop.

Zdroj: https://hermes-agent.nousresearch.com/docs/getting-started/installation · https://hermes-agent.nousresearch.com/docs/user-guide/desktop · https://hermes-agent.nousresearch.com/docs/user-guide/import-from-other-agents

2Model: Claude Team přes DirectSDK

  1. Přijmi pozvánku do firemního Claude Team (e-mail od Anthropicu).
  2. Nainstaluj Claude Code, v PowerShellu: irm https://claude.ai/install.ps1 | iex. Pak otevři nové okno terminálu.
  3. Přihlas se: napiš claude → „Claude account with subscription“ → vyber organizaci Team → Authorize.
  4. V Hermes Desktop: Capabilities → Plugins → „Claude Subscription DirectSDK“ → Install.
  5. Settings → Model → Change → „Claude Subscription DirectSDK (Experimental)“ → vyber model.
  • V průvodci prvním spuštěním nevybírej „Anthropic“: vestavěné přihlášení Claude čerpá jen placené extra usage, ne limity předplatného. Když průvodce DirectSDK nenabídne, zvol zatím ChatGPT svým účtem a po krocích 4–5 přepni.
  • Doúčtování nad limit (u Team „usage credits“) nech vypnuté; zapíná ho vlastník organizace.
  • Na Windows Anthropic doporučuje Git for Windows (winget install Git.Git).
  • S účtem Team jsme plugin nezkoušeli; Claude Code přihlášení k Team oficiálně podporuje. Záloha: ChatGPT v Settings → Providers (Go má Codex jen omezeně).
  • API kredity Team (20 $ měsíčně na Standard seat, sdílené): vlastník je po 7 dnech vyzvedne na claude.ai → Organization settings → Billing → API credits.

Zdroj: README pluginu DirectSDK · https://hermes-agent.nousresearch.com/docs/integrations/providers (Anthropic) · https://hermes-agent.nousresearch.com/docs/user-guide/configuring-models · https://code.claude.com/docs/en/quickstart · https://support.claude.com/en/articles/11845131-use-claude-code-with-your-team-or-enterprise-plan

3Kontrola

Napiš Hermesovi: „Zkontroluj, jestli ti něco nechybí, a řekni mi, jaký model používáš.“ Diagnostiku si spustí sám. Záloha v terminálu: hermes doctor.

4Osobní Telegram bot (jen soukromé zprávy)

V Desktopu: Messaging → Telegram → Create with QR. Naskenuj kód v Telegramu; Hermes založí bota, zjistí tvoje ID a nastaví tě jako jediného povoleného uživatele.

Ručně: v Telegramu napiš @BotFather → /newbot → zkopíruj token (nikomu ho neposílej). Své číselné ID zjistíš u @userinfobot. Obojí vlož v Desktopu do Messaging → Telegram.

Bota nepřidávej do skupin. Bot bere i hlasové zprávy.

Zdroj: https://hermes-agent.nousresearch.com/docs/user-guide/messaging/telegram

5Discord

  1. Na https://discord.com/developers/applications klikni New Application.
  2. Záložka Bot → Reset Token → zkopíruj token. Zobrazí se jen jednou.
  3. Na stránce Bot zapni Message Content Intent a Server Members Intent.
  4. Pozvi bota na server (OAuth2 URL s rozsahy bot a applications.commands; oprávnění 309237763136): https://discord.com/oauth2/authorize?client_id=<APP_ID>&scope=bot+applications.commands&permissions=309237763136
  5. V Hermes Desktop Messaging → Discord: vlož token, jako povoleného uživatele jen sebe (své Discord ID) a zapni odpovídání jen na zmínku.
  • Své ID zkopíruješ po zapnutí Developer Mode v Discordu (Settings → Advanced).
  • Bez povoleného uživatele bot neodpoví nikomu. Každý bot poslouchá jen svého člověka.
  • Když ho zmíníš, přečte si, co v kanálu padlo od jeho poslední odpovědi (nejvýš 50 zpráv). Zprávy ostatních bere jako informaci, ne jako pokyn. Ve vlákně vidí jen to vlákno.

Zdroj: https://hermes-agent.nousresearch.com/docs/user-guide/messaging/discord

6Balík skills (všichni)

Repozitář je veřejný, žádné pozvánky. Vlož do Hermese celý blok z README repa github.com/acegraphx/hermes-team-skills, sekce „Prompt pro agenta“. Agent si balík naklonuje, zapne, zamkne, založí ti osobní wiki, ke každé skill napíše, co bude dělat jinak, a zeptá se, co chceš přizpůsobit. Trvá to asi 3 minuty. Potřebuje jen Git (na Windows winget install Git.Git).

7Firemní mozek

Šéf: založení mozku (jednou)

Předpoklad: placený GitHub (Team) a GitHub CLI přihlášené účtem správce organizace: winget install GitHub.cli, nové okno terminálu, gh auth login.

Napiš Hermesovi

Založ v naší organizaci <název organizace> na GitHubu soukromé repo company-brain ze šablony acegraphx/company-brain-template a nastav ho podle jeho SETUP-GITHUB.md. Vlastníky oblastí nastav na konkrétní lidi: <GitHub jméno šéfa> rozhodnutí, produkt, zakázky a pravidla, <GitHub jméno hlavního vývojáře> architektura a runbooky. Zapni kontrolu brain-check a ochranu hlavní větve. Nejdřív mi ukaž, co přesně uděláš.

Na zapnutí kontroly si agent řekne o oprávnění workflow (gh auth refresh -s workflow), to potvrdíš v prohlížeči. Vyzkoušeno 10. 11.: po nastavení GitHub přímý zápis do hlavní větve odmítne i správci.

Šéf: úvodní onboarding o firmě

Napiš Hermesovi

Projdi náš web synergit.cz a dokumentaci produktu SGM a založ v mozku základní stránky o firmě. Nejdřív mi ukaž plán po oblastech.

Agent ukáže plán, po souhlasu připraví jeden pull request na oblast se stránkami s nízkou důvěrou. Vyzkoušeno 10. 11.: z webu 8 stránek o SGM v jednom návrhu, kontrola bez chyb.

Vývojáři: kopie mozku a schválení

  1. winget install GitHub.cli, nové okno terminálu, gh auth login (na otázku „přihlásit i Git?“ odpověz ano).
  2. Řekni Hermesovi:
    Napiš Hermesovi

    Naklonuj firemní mozek <organizace>/company-brain do ~/company-brain, nastav v něm svůj podpis „Hermes (Jméno Příjmení)“ podle AGENTS.md a zapiš si do paměti, kde mozek je.

  3. Onboarding své oblasti schval v GitHubu: pull request → Files changed → Review changes → Approve. Shrnutí ti připraví Hermes: „Shrň mi pull request <číslo> v mozku a řekni, co mám zkontrolovat.“

Jeden člověk: týdenní kontrola zastarání

Stačí jeden Hermes, třeba hlavního vývojáře:

Napiš Hermesovi

Každé pondělí v 8:00 stáhni čerstvou verzi firemního mozku a založ v GitHubu jedno issue se stránkami, kterým vypršela kontrola, a označ v něm jejich vlastníky.

Hlavní firemní agent není potřeba: každý má svého Hermese, porady zpracovává Hermes toho, kdo poradu vedl.

První úkoly v mozku

V Hermes Desktop vyber v postranním panelu projekt company-brain a otevři v něm nový chat. Hermes při startu načte pravidla z AGENTS.md.

  1. Napiš Hermesovi

    Přečti pravidla tohohle repa a vysvětli mi vlastními slovy, jak smíš měnit firemní mozek. Nic neměň.

  2. Napiš Hermesovi

    Zapiš do mozku pojem „<pojem>“ do slovníčku. Zdroj: <odkaz>.

  3. Napiš Hermesovi

    Zkontroluj stránku <stránka> proti aktuálnímu kódu v <repo>. Když něco nesedí, navrhni opravu a napiš, co přesně jsi ověřil.

Agent zakládá návrhy sám podle pravidel v repu: vlastní větev, podpis, zdroj, kontrola formátu. Slučuje vždy člověk.

8Osobní wiki

Paměť agenta je malá, pár řádků. Vlastní poznámky a znalosti patří do osobní wiki: složka s textovými soubory jen pro tebe, agent do ní píše sám a nic se neschvaluje. Balík skills ji založí při instalaci. Bez balíku:

Napiš Hermesovi

Založ si moji osobní wiki ve složce ~/wiki a zapiš si do paměti, že „poznamenej si“ znamená zápis tam a „zapiš to do mozku“ návrh do firemního mozku.

  • „Poznamenej si…“ → osobní wiki (krátká preference do paměti).
  • „Zapiš to do mozku…“ → návrh do firemního mozku, schvaluje člověk.
  • Když agent neví, zeptá se: „Jen pro tebe, nebo pro celý tým?“ Vyzkoušeno 10. 11.
Když něco nejde: napiš Hermesovi „Zkontroluj, jestli ti něco nechybí, a oprav to. Nejdřív mi řekni, co uděláš.“ Po instalaci čehokoli v terminálu otevři nové okno.
